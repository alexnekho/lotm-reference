# Иллюстративные знаки организаций

Эти изображения созданы для навигации по справочнику. Они не заявлены как официальная геральдика мира книги.

Режим создания: встроенная генерация изображений. Общая установка: оригинальный центральный знак на тёмном текстурном фоне, фактура старинной металлической гравюры, тонкий орнамент, палитра полуночного синего, угля и старого золота; широкий формат 3:2, читаемость в маленькой карточке, без надписей, зданий и портретов. Для единства серии первое изображение использовалось как стилевой образец при генерации следующих девяти.
