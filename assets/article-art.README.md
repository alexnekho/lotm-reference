# Иллюстрации статей

Созданы встроенной генерацией изображений для справочных карточек и страниц о мистике, продвижении, мире и существах. Общая установка для серии: широкая сцена 3:2, тёмная живописная фактура старой гравюры, свечной свет, викторианские предметы, полуночный синий и старое золото, ясный смысловой центр, без надписей. Иллюстрации не добавляют сведений к тексту книги.
